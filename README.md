# GIA-style practice test

Independent timed practice in the format of the Thomas International GIA (reasoning, perceptual speed, number speed and accuracy, word meaning, spatial visualisation).

- Fresh items are generated on every run.
- Each section has optional practice items with feedback, then a timed block with none.
- Lengths are full (about 16 minutes), half, or 1 minute per section.
- Results show raw score, accuracy and a penalty-adjusted score.
- History and per-section trends stay in your browser.

This tool is not affiliated with Thomas International. It does not use their items or norms, and its scores are practice scores only.

## Run locally

```sh
npm install
npm run dev
npm test
```

## Deploy

Every push to `main` runs the tests, builds, and deploys to GitHub Pages. In the repo settings, set Pages to deploy from GitHub Actions.
